# 🛡️ Escudo Sónico Multiespecie - Versión 4.0 (100% Silencioso para Humanos)

Aplicación web progresiva (PWA) de ultra-frecuencia pura sin distorsión.

🔇 **Garantía Total:** Todas las frecuencias han sido calibradas estrictamente por encima de los **20,800 Hz hasta 23,500 Hz** con **ondas senoidales puras y control de saturación**.
- **0% Ruido para humanos**: No emite zumbidos, ni pitos agudos que duelan la cabeza, ni ruidos de motor.
- **100% Impacto en plagas**: Inaudible para personas, pero insoportable para gatos, perros, zancudos, murciélagos, lagartijas y plagas de jardín.

🌐 **Enlace directo a la aplicación:**  
👉 **[https://gmph2007.github.io/escudo-sonico-repelente/](https://gmph2007.github.io/escudo-sonico-repelente/)**

## 🔄 Cómo actualizar en tu celular si tenías la versión anterior guardada
Si en tu celular ves los botones viejos (como 4.2 kHz o 17.4 kHz):
1. Abre el enlace en tu navegador.
2. Toca el botón arriba a la derecha: **"🔄 Limpiar Caché"**.
3. La página se refrescará automáticamente con la **Versión 4.0**.
