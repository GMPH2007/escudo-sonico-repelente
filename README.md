# 🛡️ Escudo Sónico Multiespecie - Versión 5.0 (Segundo Plano Activo y 100% Offline)

Aplicación web progresiva (PWA) de ultra-frecuencia pura diseñada para proteger tu hogar de manera continua.

### 🌟 Nuevas Características de la Versión 5.0:
1. **🎧 Funcionamiento en Segundo Plano (Background Audio & MediaSession):**
   - Ahora puedes bloquear la pantalla de tu celular, apagar la pantalla o cambiar de aplicación (abrir WhatsApp, etc.) y **el escudo sónico sigue funcionando sin interrupción**.
   - Integra la API de `MediaSession` de Android para mostrar el reproductor en la barra de notificaciones y pantalla de bloqueo.
2. **🧹 Interfaz Limpia (Sin Banners si ya está instalada):**
   - Cuando abres la aplicación desde el ícono instalado en tu celular, el botón de instalación se oculta por completo de forma automática.
   - También incluye el botón **"✕ Ya la instalé"** para quitarlo manualmente si lo prefieres.
3. **🚨 Patrullaje 360° Nocturno Inteligente:**
   - Modo prioritario que va rotando de forma segura cada 12 segundos entre gatos, perros, zancudos, murciélagos, serpientes y plagas, blindando tu casa durante toda la noche.
