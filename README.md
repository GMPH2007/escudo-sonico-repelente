# 🛡️ Escudo Sónico Multiespecie - Versión 9.0 (Aturdimiento y Sobrecarga Sónica)

Aplicación web progresiva (PWA) con motor de **aturdimiento acústico de grado militar y sobrecarga sensorial para animales**.

### 💥 Nuevas Características de la Versión 9.0:
1. **🚨 Aturdimiento Acústico Militar (2,600 - 4,800 Hz):**
   - Basado en los principios de dispersión acústica de largo alcance (LRAD).
   - Genera una **doble onda en diente de sierra + cuadrada con modulación caótica a 12 Hz** y saturación `WaveShaper`.
   - Provoca saturación inmediata de la cóclea y pérdida de equilibrio en perros y gatos, forzando la huida inmediata.
2. **⚡ Sobrecarga Cóclea Ultrasónica (22 - 25 kHz Ráfaga):**
   - Bombardeo ultrasónico continuo e inaudible para humanos, letal para la orientación de ratas y roedores.
3. **📢 Máximo Poder en Parlante Bluetooth:**
   - Aprovecha al 100% la potencia de salida RMS sin pérdida de decibeles.
4. **🔬 Fórmulas de Exterminio 100% Efectivas:**
   - Recetas probadas para erradicar cucarachas, hormigas, zancudos, ratas y serpientes.
