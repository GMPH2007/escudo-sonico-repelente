# 🛡️ Escudo Sónico Multiespecie - 100% Silencioso para Humanos (PWA)

Aplicación web progresiva (PWA) con motor de **ondas senoidales puras de ultra-alta frecuencia (18,800 Hz a 25,500 Hz)**.

🔇 **Garantía Acústica:** **100% Inaudible para personas adultas**. No hace ruidos feos, chirridos, pitos ni zumbidos molestos en la casa. Emite ultrasonido a máxima potencia que solo los animales y plagas perciben.

👉 **[https://gmph2007.github.io/escudo-sonico-repelente/](https://gmph2007.github.io/escudo-sonico-repelente/)**

## ⚡ 100% Funcional Sin Internet (Modo Offline)
Esta aplicación está programada con arquitectura **PWA (Progressive Web App)** con Service Worker:
1. Al abrirla por primera vez, el sistema guarda en la memoria de tu teléfono todos los componentes.
2. Puedes apagar los datos móviles, el Wi-Fi o poner tu teléfono en **Modo Avión**, y la aplicación seguirá funcionando exactamente igual.
